#  Sales Control

**Sales Control** es un sistema de ventas e inventario migrado de PHP a Java usando Spring Boot y MySQL.

##  Tecnologías

- Java 17+
- Spring Boot
- MySQL
- JPA / Hibernate
- Maven


##  Configuración del entorno

1. Clona el repositorio:
   ```bash
   git clone https://github.com/tuusuario/sales_control.git

2. Crea una base de datos en MySQL:
   CREATE DATABASE sales_control_db;

3. Configura application.properties con tus datos de acceso a MySQL.

4. Ejecuta el proyecto:
   ./mvnw spring-boot:run

## Funcionalidades

- Gestión de usuarios
- Gestión de productos e inventario
- Registro de ventas
- Administración de clientes y categorías

## Estado del proyecto

- Migración en curso desde PHP a Java.
